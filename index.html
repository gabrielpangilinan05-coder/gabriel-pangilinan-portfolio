EPPMA — Extension Program and Project Management Application

Pangasinan State University (PSU)

Role: Developer · Capstone system

AI-powered web system

Problem

Extension programs were mostly paper-based or scattered across Excel, docs, and email. Proposal submissions, staff reviews, implementation tasks, and monitoring schedules were hard to track — causing delayed approvals, missing status updates, and little visibility on which projects were ongoing or done.

What I built

An AI-powered web system that streamlines the extension program lifecycle: proposal creation and review, Kanban-style implementation tracking, monitoring calendar, role-based dashboards, and reporting — all in one platform.

How it works

  1. Login — Faculty, staff, or admin sign in with email/password or Google OAuth and role-based access.
  2. Input — Faculty Extensionist creates or uploads a proposal; reviewers add comments and approvals.
  3. Process — Approved projects move through To Do → In Progress → Done with scheduled dates and times.
  4. Monitor — Tasks sync to a color-coded Monitoring Calendar with clickable details.
  5. Output — Dashboards show progress, staffing, and monitoring across programs.

Result

Built as a school capstone system for PSU Extension Program management — designed for proposal workflow, project implementation tracking, and calendar-based monitoring.
